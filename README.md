# Criptografia-com-Progress-es-e-S-ries-Matem-ticas-em-C
Desenvolvimento de um programa em C para criptografar e descriptografar palavras utilizando a Cifra de César, progressões aritméticas e geométricas, sequência de Fibonacci e números primos. O projeto aplica conceitos de lógica de programação, algoritmos, funções e manipulação de arquivos.
